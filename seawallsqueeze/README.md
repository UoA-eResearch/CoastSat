# CSV Workspace

Starter Python workspace for working with `seawall_distance.csv`.

## Structure

- `data/` - place CSV files here
- `src/main.py` - starter script to load and preview CSV
- `notebooks/` - optional notebooks
- `requirements.txt` - Python dependencies

## Quick start

1. Put your CSV at `data/seawall_distance.csv`
2. Install deps:

```bash
pip install -r requirements.txt
```

3. Run:

```bash
python src/main.py
```
